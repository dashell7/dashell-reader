# 朗读组件替换

2026-10-13，按用户要求，Dashell Reader 改用 Qiaomu Reader 的整套朗读组件，删除此前的 Aloud 播放、服务、设置、语言选择和控制栏模块。查词、生词库、复习与划线继续使用 Dashell 实现。

## 来源与接入

本轮上游整合基线为 Qiaomu Reader `4.7.5`，commit `ae919610aa6abf34267ebaae44128d3f7e489bf5`。朗读组件固定为 `4.7.4`，commit `8873f08404f68e8cae5174e28ea2ea6c5bf32e95`；4.7.5 没有修改 `tts-*`。

移入 `src/tts-*`：播放控制、正文分块、朗读位置、预加载与缓存、语音服务、音色选择与试听、Edge 请求调度、Mac 语音、本地模型管理、模型清单及 Python 运行脚本。工具栏、选文菜单、已保存划线菜单统一调用同一播放器。阅读视图关闭、换书及插件卸载释放朗读任务与播放资源。

相对于上游的适配仅包括 Dashell 试听名称、独立的本地模型/缓存目录、保留既有密钥引用，以及 `_saveLocalData()` 返回 `false` 时显示保存失败。模型与缓存独立于 Obsidian 库；与 Qiaomu Reader 同时安装时不共享本地工作目录。

服务：Edge、系统语音、Mac 本地语音、本地模型、OpenAI、兼容 OpenAI、通义千问、豆包、MiniMax、硅基流动、ElevenLabs、Azure。保留上游平台限制：Mac 服务在其他平台隐藏；本地模型安装与 Edge 使用桌面能力。服务已接入不等于全部账号、平台均已实测。

## 既有设置迁移

`tts-migration.js` 将 Aloud 设置一次性转换到 `settings.tts`。已经存在的新格式优先；迁移在读取完整阅读数据后持久化。

- Azure 保留区域、音色和 SecretStorage 引用；旧音频编码不当作模型名。
- OpenAI、兼容接口、ElevenLabs、MiniMax 保留已有共同配置。兼容接口保留实际请求地址；MiniMax 保留原国内/国际站选择。
- 保留原播放倍速并按新组件的范围校验。
- 新组件没有的旧服务与选项不再参与播放，仅留在原配置记录中，供回退到旧版本使用。
- 迁移不读取、删除或重建密钥，不改写词库和复习数据。

删除的 `selection-tts*.js` 不再进入构建，也不保留旧播放器或第二套设置。Aloud 历史许可保留。Edge 互操作许可与 WebSocket MIT 声明随资产分发；构建保留许可证的原始段落和空白。
