# Dashell Reader 4.4.7

发布日期：2026-10-20。本版将 4.4.6 之后已合入的更新打包发布，选择性适配截至 Qiaomu Reader 4.7.8 的正式版本，保留 Dashell 的英语学习功能。

## 主要更新

- **完整朗读**：以 Qiaomu 朗读组件替换 Aloud，统一阅读工具栏、选文和已保存划线的朗读入口，支持连续播放、音色试听、暂停/继续、调速、正文跟随与位置接续。
- **更多语音选择**：接入 Edge、系统语音、Mac 语音、本地模型及在线服务，按设备提供可用选项；修复 Windows 本地模型安装的归档路径匹配与部分安装恢复。
- **阅读更稳定**：恢复 EPUB/MOBI 跨章节划线，修复后台标签加载与关闭后的布局回调，完善窄窗口、主题和分隔线。
- **书库更安全**：从书库移除可以撤销；删除源文件单独确认并遵循宿主回收站；清理磁盘划线与备份，避免路径复用后旧划线重现。
- **文档与 AI**：增加 TXT/HTML 阅读和编码处理，更新账号/服务及模型目录、Agent 检测和连接验证；DeepSeek 默认使用 Flash，思考模式显式使用 high，仅迁移官方地址下的旧 Flash 模型名。
- **保留定制能力**：英语查词、生词库、跨文件标记、Spaced Repetition、Obsidian Markdown 渲染及 RSS 各版本阅读进度继续使用 Dashell 实现。

## 升级与隐私

- 插件 ID 仍为 `dashell-reader`，最低 Obsidian 版本仍为 1.11.4。使用 BRAT 更新，或下载本 Release 的 `main.js`、`manifest.json`、`styles.css` 替换插件目录内的同名文件并重载；保留 `data.json`、学习记录和其他文件。
- 已有共同语音服务的配置、Azure 区域/音色与密钥引用会迁移；不再支持的旧 Aloud 选项仅保留作回退记录。建议升级前备份插件数据和笔记。
- 桌面默认 Edge 朗读会把选定的文字发送给微软；其他在线服务将文字发送到对应服务。本地语音在设备上合成，本地模型首次安装需要联网下载。
- 本项目通过 GitHub 分发，尚未进入 Obsidian 社区目录；本次仅发布 GitHub，不提交官方目录或执行官方预扫描。

当前源码已通过 592 项 Node 测试、6 项 Python 本地模型安装测试、八语言检查、源码 ESLint、学习模块类型检查、标准/社区构建和发布资产检查。

此前在指定 Windows Obsidian 1.14.4 测试库完成 Azure 实际播放与控制、旧设置迁移、跨章节划线、窄窗口、生词标记及重载保留检查；4.7.8 增量另做 Windows 安装夹具与宿主重载检查。Mac、移动实机、其他在线账号、本地模型真实下载/合成、PDF 整书朗读与冷启动未覆盖；本地安装夹具不代表这些能力的实机验收。
