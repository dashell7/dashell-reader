# Dashell Reader 4.5.1

本版补齐阅读、查词、收词到复习的连续操作，并修复学习草稿和失败恢复问题。保留现有插件 ID、词库与阅读数据。

- **保存后有下一步**：生词本展示真实集合，支持按单词或含义搜索；保存后可直接查看当前词或开始复习。复习沿用 Spaced Repetition，未启用时会说明所需操作；同步失败不会打开旧复习内容。
- **草稿可靠**：在不同查询之间切换会保留各词草稿；旧请求和旧保存结果不会覆盖当前编辑内容。
- **失败可恢复**：字典、书内搜索及 Calibre 提供错误与重试；书内搜索失败后，保留原词再次按 Enter 即可重新请求。
- **窄窗口可读**：只在本插件学习任务可见时临时限制本插件侧栏宽度；可用阅读区较窄时，阅读笔记在同组标签页打开，原书保留。离开学习任务后撤销临时侧栏限制。
- **操作更明确**：目录、划线、历史使用可聚焦按钮；表单错误关联字段；书库空结果可一键恢复；找书按钮明确当前搜索来源。

复习功能需要启用 Spaced Repetition。更新后在命令面板执行“打开生词本”，即可查看已保存内容；也可从收词面板进入。

发布验证包含自动测试、学习模块类型检查、语言包检查、生产构建、发布资产校验和 Windows 桌面宿主检查。指定1024×800场景中，正文由约109px恢复到488px；该数值与测试库侧栏布局相关，不代表所有默认布局。

真实 Calibre 服务、手机真机、完整读屏流程和复习评分后的状态回流未在本轮端到端验收。没有改造现有复习卡片界面。

本项目通过 GitHub Release、BRAT及手动安装分发，尚未进入 Obsidian 社区插件目录。本次不申请社区目录上架。
