# Dashell Reader 4.5.0

发布日期：2026-11-03。本版选择性适配 Qiaomu Reader 4.9.4 的 Hacker Books 书单浏览与本地阅读清单，保留 Dashell 的阅读、英语学习、Gutenberg 下载和既有书源。

## 主要更新

- **浏览公开书单**：在“找书”中浏览值得读、最多人提及和经典常青等列表，按主题筛选，或在本地搜索书名和作者。
- **查看书籍详情**：阅读书目简介、HN 读者评论、阅读建议与相关书籍，再选择现有外部书源或 Gutenberg 公版搜索。
- **本地阅读清单**：标记“想读”或“读过”，并根据本地书库和清单计算推荐。清单仅保存在 Reader 插件设置中，不上传到书目服务。
- **隐私和恢复**：搜索及推荐在本地计算；浏览会下载公开书目和封面，打开详情会请求该书公开 ID，服务仍可见请求 IP。书单加载失败可重试，保存失败会恢复原状态并允许重试。

本版未增加运行时依赖。最低 Obsidian 版本保持为 1.11.4。

## 安装与升级

插件 ID 仍为 `dashell-reader`。通过 BRAT 更新，或从本 Release 下载 `main.js`、`manifest.json` 和 `styles.css`，替换插件目录内三个同名文件后重载。保留 `data.json`、阅读进度、学习记录和其他文件。

本项目通过 GitHub 分发，未提交 Obsidian 社区插件目录；本次仅发布 GitHub Release。

## 验证与边界

本地回归为 646 个 Node 测试、6 个 Python TTS 测试；语言、学习类型与源码 ESLint 检查通过。宿主安装、构建、发布资产与 CI 结果见 [4.9.4 适配记录](../DASHELL-QIAOMU-READER-494.md)，并在最终发布时补录资产摘要。

本版没有升级依赖或 lockfile；依赖审计风险以最终适配记录中的本轮核验为准。物理移动设备、macOS 和真实 AI 服务未作为本次功能验收范围。
