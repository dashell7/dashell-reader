# Dashell Reader 4.4.9

发布日期：2026-11-03。本版选择性适配 Qiaomu Reader 4.9.3 的 AI 快捷提示词管理，保留 Dashell 的阅读、英语学习与阅读数据。

## 主要更新

- **自定义 AI 快捷提示词**：为按钮设置显示名称和完整提示词正文，新增、编辑、删除最多 20 条提示词；AI 伴读的快捷按钮与斜杠菜单共用同一份列表。
- **默认值与保存恢复**：可恢复按界面语言提供的默认提示词。删除全部提示词后仍可打开管理器；编辑草稿在保存前不会生效，保存失败时保留草稿并可重试。
- **更新入口**：AI 伴读快捷栏与 AI 设置均可打开同一管理器；保存后刷新已打开的侧栏和模态窗口。

提示词只作为文本数据保存并发送到用户已选择的 AI 服务。不会更改服务、模型、地址、密钥或学习记录。没有发起真实模型请求。

## 安装与升级

插件 ID 仍为 `dashell-reader`，最低 Obsidian 版本仍为 1.11.4。通过 BRAT 更新，或下载本 Release 的 `main.js`、`manifest.json` 和 `styles.css`，替换插件目录内的三个同名文件后重载；保留 `data.json`、阅读进度、学习记录和其他文件。

本项目通过 GitHub 分发，尚未进入 Obsidian 社区插件目录；本次仅发布 GitHub Release。
